## 📦 Требования

### Требования к серверу

**Для PHP-бота (общий хостинг):**
- PHP >= 8.1
- MySQL/MariaDB >= 5.7
- Apache/Nginx с mod_rewrite
- Расширение cURL
- Расширение PDO MySQL
- Расширение mbstring
- Расширение GD (для QR-кодов)
- Расширение BCMath
- Права на запись для логов и загрузок

**Для Python-бота (VPS):**
- Python 3.9+
- MySQL/MariaDB >= 5.7
- Nginx (рекомендуется)
- Systemd (для управления службами)

### Расширения PHP

- `pdo_mysql` - Подключение к базе данных
- `curl` - HTTP-запросы
- `json` - Обработка JSON
- `mbstring` - Обработка многобайтовых строк
- `gd` - Обработка изображений (QR-коды)
- `bcmath` - Математические операции

### Библиотеки PHP (Composer)

- `endroid/qr-code` ^4.0 - Генерация QR-кода
- `guzzlehttp/guzzle` ^7.0 - HTTP-клиент

## 🚀 Быстрый старт

### 📦 Автоматическая установка (рекомендуется)

#### Для общего хостинга

1. Загрузите все файлы проекта на ваш хостинг
2. Перейдите по адресу: `https://yourdomain.com/installer/host/install.php`
3. Следуйте мастеру установки:
   - Шаг 1: Проверка требований
   - Шаг 2: Настройка базы данных
   - Шаг 3: Настройка бота
   - Шаг 4: Автоматическая установка
   - Шаг 5: Готово!

#### Для VPS (Ubuntu/Debian)

```bash
# Установка одной командой
sudo bash <(curl -sSL https://raw.githubusercontent.com/iitzSeriZdev/iRolixBot/main/installer/vps/install.sh) install

# Удаление с резервной копией
sudo bash <(curl -sSL https://raw.githubusercontent.com/iitzSeriZdev/iRolixBot/main/installer/vps/install.sh) uninstall-with-backup

# Прямое обновление
sudo bash <(curl -sSL https://raw.githubusercontent.com/iitzSeriZdev/iRolixBot/main/installer/vps/install.sh) update
```

**После установки:**

1. Учетные данные базы данных сохраняются в `/tmp/irolix_db_config`
2. Отредактируйте `/opt/iRolixBot/bot-php/config.php`, чтобы добавить токен вашего бота
3. Получите доступ к панели по адресу `http://YOUR_SERVER_IP/web-panel`
4. Завершите настройку через веб-интерфейс

### 📦 Ручная установка

Если вы предпочитаете ручную установку:

#### Шаг 1: Клонирование репозитория

```bash
git clone https://github.com/iitzSeriZdev/iRolixBot.git
cd iRolixBot
```

#### Шаг 2: Установка зависимостей

```bash
cd bot-php
composer install
```

#### Шаг 3: Настройка базы данных

Создайте базу данных MySQL/MariaDB и запишите учетные данные.

#### Шаг 4: Создание Telegram-бота

1. Отправьте сообщение @BotFather в Telegram
2. Используйте `/newbot` для создания вашего бота
3. Безопасно сохраните токен бота

#### Шаг 5: Запуск установки

1. Загрузите файлы на ваш веб-сервер
2. Посетите `installer/host/install.php` в браузере
3. Следуйте интуитивному мастеру установки:
   - Выберите ваш язык
   - Введите данные базы данных
   - Настройте токен бота
   - Настройте учетную запись администратора
   - Завершите установку

#### Шаг 6: Настройка Cron Jobs

Настройте **только один cron job**:

```bash
* * * * * /usr/bin/php /path/to/iRolixBot/bot-php/cron/cron.php >> /path/to/iRolixBot/Logs/cron_output.log 2>&1
```

Или используйте HTTP:

```bash
* * * * * curl -s https://yourdomain.com/bot-php/cron/cron.php > /dev/null 2>&1
```

**Вот и все!** Централизованный менеджер автоматически обрабатывает все. 🎉
