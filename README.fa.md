## 📦 نیازمندی‌ها

### نیازمندی‌های سرور

**برای ربات PHP (هاست اشتراکی):**
- PHP >= 8.1
- MySQL/MariaDB >= 5.7
- Apache/Nginx با mod_rewrite
- افزونه cURL
- افزونه PDO MySQL
- افزونه mbstring
- افزونه GD (برای QR Code)
- افزونه BCMath
- مجوز نوشتن برای لاگ‌ها و آپلودها

**برای ربات Python (VPS):**
- Python 3.9+
- MySQL/MariaDB >= 5.7
- Nginx (توصیه می‌شود)
- Systemd (برای مدیریت سرویس)

### افزونه‌های PHP

- `pdo_mysql` - اتصال به پایگاه داده
- `curl` - درخواست‌های HTTP
- `json` - پردازش JSON
- `mbstring` - مدیریت رشته‌های چندبایتی
- `gd` - پردازش تصویر (QR Code)
- `bcmath` - عملیات ریاضی

### کتابخانه‌های PHP (Composer)

- `endroid/qr-code` ^4.0 - تولید QR Code
- `guzzlehttp/guzzle` ^7.0 - کلاینت HTTP

## 🚀 شروع سریع

### 📦 نصب خودکار (توصیه می‌شود)

#### برای هاست اشتراکی

1. تمام فایل‌های پروژه را به هاست خود آپلود کنید
2. به آدرس بروید: `https://yourdomain.com/installer/host/install.php`
3. دستورالعمل نصب را دنبال کنید:
   - مرحله 1: بررسی نیازمندی‌ها
   - مرحله 2: پیکربندی پایگاه داده
   - مرحله 3: پیکربندی ربات
   - مرحله 4: نصب خودکار
   - مرحله 5: تکمیل!

#### برای VPS (Ubuntu/Debian)

```bash
# نصب با یک دستور
sudo bash <(curl -sSL https://raw.githubusercontent.com/iitzSeriZdev/iRolixBot/main/installer/vps/install.sh) install

# حذف با پشتیبان‌گیری
sudo bash <(curl -sSL https://raw.githubusercontent.com/iitzSeriZdev/iRolixBot/main/installer/vps/install.sh) uninstall-with-backup

# بروزرسانی مستقیم
sudo bash <(curl -sSL https://raw.githubusercontent.com/iitzSeriZdev/iRolixBot/main/installer/vps/install.sh) update
```

**پس از نصب:**

1. اطلاعات پایگاه داده در `/tmp/irolix_db_config` ذخیره می‌شود
2. فایل `/opt/iRolixBot/bot-php/config.php` را ویرایش کنید تا توکن ربات را اضافه کنید
3. به پنل در `http://YOUR_SERVER_IP/web-panel` دسترسی پیدا کنید
4. تنظیمات را از طریق رابط وب تکمیل کنید

### 📦 نصب دستی

اگر ترجیح می‌دهید نصب دستی انجام دهید:

#### مرحله 1: کلون کردن مخزن

```bash
git clone https://github.com/iitzSeriZdev/iRolixBot.git
cd iRolixBot
```

#### مرحله 2: نصب وابستگی‌ها

```bash
cd bot-php
composer install
```

#### مرحله 3: راه‌اندازی پایگاه داده

یک پایگاه داده MySQL/MariaDB ایجاد کنید و اطلاعات را یادداشت کنید.

#### مرحله 4: ایجاد ربات تلگرام

1. به @BotFather در تلگرام پیام دهید
2. از `/newbot` برای ایجاد ربات خود استفاده کنید
3. توکن ربات را به صورت امن ذخیره کنید

#### مرحله 5: اجرای نصب

1. فایل‌ها را به سرور وب خود آپلود کنید
2. `installer/host/install.php` را در مرورگر خود بازدید کنید
3. دستورالعمل نصب را دنبال کنید:
   - زبان خود را انتخاب کنید
   - جزئیات پایگاه داده را وارد کنید
   - توکن ربات را پیکربندی کنید
   - حساب ادمین را تنظیم کنید
   - نصب را تکمیل کنید

#### مرحله 6: تنظیم Cron Jobs

**فقط یک cron job** پیکربندی کنید:

```bash
* * * * * /usr/bin/php /path/to/iRolixBot/bot-php/cron/cron.php >> /path/to/iRolixBot/Logs/cron_output.log 2>&1
```

یا از HTTP استفاده کنید:

```bash
* * * * * curl -s https://yourdomain.com/bot-php/cron/cron.php > /dev/null 2>&1
```

**همین!** مدیر متمرکز همه چیز را به صورت خودکار مدیریت می‌کند. 🎉
